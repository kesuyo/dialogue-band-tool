# 帯テキスト一括合成ツール v1.8

セリフなし画像フォルダ + 台本CSV から、**セリフあり画像版**または**ブラウザで読める HTML ノベルビューア（文字なし画像＋シナリオ＋HTML）**を一括生成します。
元の画像は変更しません。画像版はセリフのない画像がそのままコピーされる（または `--uniform-height` で空帯を付けて縦横比を揃える）ため、出力フォルダがそのまま「セリフあり版」の完成品になります。
セリフなし版（元のフォルダ）や HTML ビューアと合わせて、DLsite / FANZA 等へ同梱できます。

## 必要なもの
- Python 3 と Pillow（`pip install pillow`）
- 日本語フォント（Windows / macOS / Linux の標準日本語フォントを自動検出します。見つからない場合や好みのフォントを使いたい場合は `--font` などでパスを指定してください）
  - **Linux**: Noto Sans CJK / Noto Serif CJK / IPAゴシック・明朝
  - **Windows**: BIZ UDゴシック・明朝 / 游ゴシック・游明朝 / メイリオ / MSゴシック・明朝
  - **macOS**: ヒラギノ角ゴシック・明朝 / Noto Sans・Serif CJK
- （任意）`budoux`（`pip install budoux`）：入っていれば日本語の文節分割精度をさらに高めます

## 使い方

### GUI で使う（おすすめ）
Windows では [launch_gui.bat](launch_gui.bat) をダブルクリックするだけで起動します（コンソール画面は出ません）。
コマンドラインから直接起動する場合：
```bash
python gui.py
```
左側の4つのタブで設定を調整しながら、右側のライブプレビューで仕上がりを確認できます：
- **基本**: 画像フォルダ・**効果音なし画像（任意・HTML用）**・台本CSV・設定JSON・`extend`/`overlay` 切替・全ページ文字サイズ統一・出力形式
- **話者・色**: 話者名デザイン（プレート/左バー/【括弧】/なし・文字サイズは本文と同一）・本文との間隔・カラーピッカー・**話者名の変更（表示名および本文中の表記置換）**
- **位置・透過**: 帯の上下配置（左揃え固定）・上下位置・左右余白・行間・透過の濃さ・グラデ幅・端マージン・文字縁取り
- **フォント・詳細**: 作品タイトル（HTML用）・HTML初期状態の効果音ON/OFF・フォント個別指定・対象キー絞り込み・見た目・話者設定のリセット

GUI 下部の **「HTMLビューア書き出し」** を押すと、指定した出力フォルダに `index.html`・`scenario.js`・`images/`（文字なし画像）が生成され、**「HTMLをブラウザで開く」** からすぐ動作確認できます。

### コマンドライン（CLI）で使う
```bash
python add_dialogue_band.py <画像フォルダ> <台本.csv> <出力フォルダ> [オプション]
```
※ Windows 環境で `python` コマンドがストア版スタブを指す場合は、インストール済み Python のフルパス（例: `C:\Users\<user>\AppData\Local\Programs\Python\Python312\python.exe`）または `py -3` で実行してください。

### 主なオプション
#### 基本
- `--mode extend|overlay` : `extend`=下に帯を継ぎ足す（既定・推奨、絵が隠れない）／`overlay`=半透明帯を重ねる（絵の縦が伸びない）
- `--band 0.24` : 帯の高さ（画像の横幅に対する比率）
- `--max-lines 2` : セリフの最大行数（既定 2）
- `--font-scale 1.0` : フォントサイズ全体の倍率（画像幅に自動比例した基準サイズに掛かります。話者名も本文と同じサイズになります）
- `--uniform-font` : 事前に全画像をスキャンし、全ページが収まる共通の最大文字サイズに自動統一
- `--uniform-height` : `extend` モード時に、セリフなし画像にも同じ高さの空帯を付けて全ページの高さを統一
- `--speaker-colors` : 話者ごとに名前の色を自動で割り当てる
- `--config PATH` : 設定JSON（[sample_config.json](sample_config.json) 参照）を読み込む（CLI引数が設定ファイルより優先）

#### 話者名・位置・透過・配色
- `--speaker-style plate|bar|bracket|plain` : 話者名の装飾スタイル（`plate`=ネームプレート風・既定 / `bar`=左バー / `bracket`=【話者名】 / `plain`=文字のみ）
- `--speaker-gap 0.50` : 話者名と本文の間隔（文字サイズに対する比率、`0.15`〜`1.50`）
- `--speaker-name 彼女=さくら` : 話者表示名を変更（複数指定可、`{{話者}}` プレースホルダも置換）
- `--replace-speaker-in-body` : 本文中の話者名表記（彼 / 彼女 等）も `--speaker-name` の変更先に置換
- `--position bottom|top` : 帯の位置（`bottom`=下端・既定 / `top`=上端、文字は左揃え固定）
- `--text-offset-y 0.0` : 帯内での文字ブロック上下微調整（`-0.35`〜`+0.35`、帯高さに対する比率）
- `--pad-x 0.045` : 左右の余白（画像幅に対する比率、既定 `0.045`）
- `--line-height 1.45` : 行間倍率（既定 `1.45`）
- `--overlay-opacity 0.76` : `overlay` 時の帯の不透明度（`0.0`〜`1.0`、既定 `0.76`）
- `--overlay-fade 0.30` : `overlay` 時のグラデーション幅（`0.0`〜`0.60`、帯高さに対する比率、既定 `0.30`）
- `--overlay-margin 0.0` : `overlay` 時の上下端からの余白（`0.0`〜`0.25`、画像高さに対する比率）
- `--text-outline 0` : 文字の縁取り太さ（`0`〜`4`、既定 `0`）
- `--band-color #0C0C0E` / `--text-color #FFFFFF` / `--narration-color #EAEDF5` : 帯色・本文色・地の文色

#### フォント・出力・チェック
- `--font PATH` / `--font-serif PATH` / `--font-bold PATH` : 本文・地の文（明朝）・話者名（太字）フォントパス
- `--format keep|png|jpg|webp` : 出力画像形式の指定（既定 `keep` は元ファイル形式を維持）
- `--quality 92` : JPEG / WebP 出力時の画質（既定 92、JPEG はサブサンプリングなし `subsampling=0`）
- `--dry-run` : 画像を書き出さず、台本照合・統一フォントサイズ・溢れチェックのみ実行
- `--strict` : CSV警告・画像未対応の台本キー・文字溢れ（切り捨て）が発生した場合にエラー終了コード 1 を返す
- `--only 001,003` : 指定した番号キーの画像だけを処理する（部分再生成用）
- `--export-html` : 画像への文字焼き込みを行わず、オフライン HTML ビューア一式（`index.html` + `scenario.js` + `images/`）を書き出す
- `--title "作品名"` : `--export-html` 時のページタイトルを指定
- `--sfx-off-dir PATH` : `--export-html` 時の効果音なし画像フォルダを指定（先頭番号キーで自動ペアリングし、`images/sfx/` と `images/nosfx/` に書き出します）
- `--default-sfx on|off` : ビューア起動時の効果音表示の初期状態（既定 `on`）
- `--sfx-label "効果音"` : ビューア側の差分切り替えボタン名を指定（既定 `効果音`）

## HTML ノベルビューア
文字が入っていない元画像フォルダと台本CSV・設定JSONから、受け取った人が `index.html` をダブルクリックするだけでブラウザ上で物語を読み進められる配布セットを生成します（ローカルファイル `file://` のまま動作・サーバー不要）。

```bash
# add_dialogue_band.py から書き出す場合
python add_dialogue_band.py sample_input sample_script.csv sample_viewer --config sample_config.json --export-html --title "作品タイトル"

# 単体スクリプトから書き出す場合
python export_html_viewer.py sample_input sample_script.csv sample_viewer --config sample_config.json --title "作品タイトル"
```

### ブラウザ側で使える機能（読者向け）
- **操作バーの自動非表示**（`M` キー / 右上 `≡` ボタン）: 上部の操作バーは普段自動で隠れ、画面上端にマウスカーソルを合わせたときや `≡` ボタン・`M` キーで表示されます（設定で常時表示にも切替可。作品タイトル未指定時はバーにフォルダ名を表示しません。スマホなど狭い画面では横スクロールなしのコンパクトな 2 段メニューとして開きます）
- **物語の進行**: 画面右側クリック / `Space` / `Enter` / `→` / ホイール / 左スワイプで次へ、**画面左端（左20%）クリック / 右スワイプ** / `←` / `Backspace` で前へ戻ります
- **同一画像での複数セリフ進行**: HTML 書き出し時は、台本CSVに同じ画像番号を複数行並べると画像を切り替えずにセリフだけ順番に進みます
- **効果音（描き文字）あり／なし切り替え**（`E` キー /「効果音 ON/OFF」ボタン）: `--sfx-off-dir`（GUI「効果音なし画像」）を指定して書き出した場合、同じページ・同じセリフのまま **効果音あり／なしを瞬時に切り替え** られます（裏で先読みするため待ち時間なし）。セリフを消して絵だけを見ている最中でも右下のボタンから見比べ可能です
- **全画面表示**（`F` キー /「全画面」ボタン）: ブラウザの枠を隠して作品全体を大きく表示できます
- **最終ページの終了案内**: 最終ページを読み終えて次に進む（またはオート再生で最後まで到達する）と「おしまい」案内が表示され、「最初から読む」「サムネ一覧」へ進めます
- **セリフの ON/OFF**（`H` キー / ボタン）: セリフ帯と操作バーを消して、文字なしの絵だけを大きく鑑賞できます（効果音切り替えと独立して4パターン表示が可能）
- **「彼」「彼女」等の名前カスタマイズ**（`N` キー /「名前設定」）: 登場話者の表示名を自由に変更可能（任意で本文中の表記も一括置換可）
- **バックログ**（`L` キー /「ログ」）: これまでのセリフ一覧を表示し、クリックしたシーンへ即ジャンプ
- **オート再生**（`A` キー /「オート」）: 文字数・句読点や改行の間・画像の切り替わり（＋α）・CGのみ表示時間まで自動計算して自然にページ送り（`1〜100` スライダーで速度調整可、タイプライター時は文字表示完了後から待機）
- **サムネ一覧**（`G` キー /「サムネ一覧」）: 左側（既定）の **「画像一覧（CG別）」** と **「シーン一覧（全ページ）」** を切り替えてサムネイルからジャンプ（効果音 ON/OFF の状態にも連動）
- **ライブ表示設定**（`S` キー /「表示設定」）:
  - 背景ブラーのないコンパクトなパネルが開くため、**下の絵とセリフの見た目を確認しながらリアルタイムに調整**できます
  - **文字背景の濃さ**・**文字サイズ**・**オート再生速度** は直感的な **1〜100（初期値 `50` が標準）** で調整可能（文字サイズは画面サイズ基準のため PC で縦型・横型画像が混在しても一定の大きさで表示、オート再生速度は右へ動かすほど速くなります）
  - **画像の下に分けて表示** を選んだ場合も帯の高さは全ページで固定されるため、行数変化やセリフなしページで画像が上下にぶれません
  - 変更した設定・名前・読書位置は開いているタブの中だけ保持され、ブラウザや端末へのデータ保存（`localStorage` 等）は一切行いません（話者名は本文と同じサイズ、文字揃えは左揃え固定、話者スタイル・縁取り・グラデ幅・上下位置は製作者設定を使用）

## 台本CSV（ヘッダなし可、UTF-8 / BOM付きUTF-8対応）
```csv
001,彼女,……ねえ、今日はもう少しだけ、そばにいて？
002,,（地の文・ナレーションは話者を空に。本文が明朝体になります）
003,彼,"「分かった。今日は帰らないで、\n朝までずっとそばにいるよ」"
```
- 番号は画像ファイル名の先頭セパレータ（`_` / `-` / 半角スペース のうち最も手前）以前と照合します（例: `001_xxx.png` / `001-a_xxx.png` → `001`）
- セリフにカンマや複数行を含めたい場合は `"..."` のようにダブルクォートで囲んでください。セル内の `\n`（または実際の改行）は手動改行としてそのまま尊重されます
- 空行と `#` で始まる行、および先頭列が `id` / `no` / `番号` のヘッダ行は無視します
- 重複キー・列不足・台本に対応する画像がない場合・画像に対応する台本がない場合は警告を出します
- 最小フォントサイズでも最大行数に収まらず末尾が切り捨てられた場合は `WARNING [OVERFLOW]` を出力します

## 組版・デザインの仕様
- **解像度自動比例**: 文字サイズ・余白・境界線・アクセントバー・縁取り・ドロップシャドウが画像幅に比例するため、低解像度〜4K画像まで崩れません
- **禁則処理**: 行頭禁則（句読点、ひらがな/カタカナ小書き `っゃゅょぁぃぅぇぉッャュョァィゥェォ`、長音・波ダッシュ・全角ダッシュ `ー〜～—―`、閉じ括弧）、行末禁則（開き括弧）、`……`/`——`/`！？` の分割禁止、英数字単語・`v1.0`/`100%` の分割禁止に対応
- **自然な折り返し**: 句読点（`。？！、，・`）や文節の区切りを優先しつつ行長バランスを最適化する動的計画法（DP）折り返しを採用。手動改行 `\n` を入れた箇所は強制維持します（任意で `budoux` も利用可）
- **視認性向上**: 帯内の垂直中央揃え（および上下微調整）、話者名のスタイル選択（プレート/左バー/括弧/なし・サイズは本文と統一）、`extend` 時の上端区切り線、`overlay` 時の上端グラデーションフェード＋文字ドロップシャドウ＋任意縁取りを実装
- **EXIF / 透過PNG対応**: スマホ等で撮影した画像の EXIF 回転を自動補正し、透過PNGは帯色背景に合成して破綻を防ぎます
